Python_Merger_Excel.py & Python Excel Merger Five Digit Secondary Key.py
========================================================================
      python_merger_Excel.py is to merge the master excel file with updates excel file using the primary code (Eg: Employer Code). It is mainly designed to process & update the Employer Code Master Excel File. More or less Vlookup using python.

       Python Excel Merger Five Digit Secondary Key.py is to merge the master excel file with updates excel file using the primary code & five digit employer code (Eg: Employer Code, Five Digit Employer Code). It is mainly designed to process & update the Employer Code Master Excel File of ESIC. Both Primary and secondary input is Five Digit Employer Code.

actual_calculation_with_adhoc.py & Adhoc_Month_Find.py
=======================================================
        actual_calculation_with_adhoc python is to calculate the actual contribution based on the input excel or csv file and missing adhoc month count. Input file should have anyother headers/footers only the table. It has dependency with Adhoc_month_Find.py file.
        These python files can be converted to *.exe using pyinstaller --onefile <python file>. Dependent file should be in the same directory.
        All the input files should be in the same directory.
